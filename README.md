# .NET Developer Portfolio

A responsive, static portfolio website built with HTML and CSS. It is designed to be published directly using GitHub Pages.

## 1. Personalize before publishing

Open `index.html` and replace these placeholders:

- `[Your Name]` and `[YOUR NAME]`
- `your.email@example.com`
- `YOUR-USERNAME`
- `YOUR-LINKEDIN`
- `[Company Name]`
- `[START DATE]`
- Education details are not included yet; add them if you want a dedicated section.

Also review each project description. Keep only technologies and responsibilities that accurately reflect your own contribution.

## 2. Publish with GitHub Pages

1. Create a new public GitHub repository. Recommended name: `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment to finish. Your site will be available at:
   `https://YOUR-USERNAME.github.io/`

If you use a repository with another name, the URL will usually be:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## 3. Suggested improvements

- Add a professional photo only if you want one.
- Add links to public code samples or demo deployments for projects you personally built.
- Add measurable outcomes only when you can verify them.
- Never publish company source code, credentials, private URLs, real user data, or confidential screenshots.
- Consider adding a downloadable PDF CV after the content is finalized.

## 4. Local preview

You can open `index.html` directly in a browser. No build tools or backend server are required.
